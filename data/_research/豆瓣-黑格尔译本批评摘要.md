抓取时间：2026-10-14。来源：豆瓣读书（`book.douban.com`，本机可直连）。
方法：`scripts/douban-scrape.mjs`（书目检索接口 `j/subject_suggest` + 书目页 + 短评页，
含 `status=P/N` 好评/差评过滤）与 `scripts/douban-analyse.mjs`、`scripts/douban-quotes.mjs`。

**抓取规模**：27 部黑格尔中译本；短评 814 条（去重后），其中 202 条直接谈翻译，30 条为负面指控。

## 一、低分到底为什么

低分**主要不是**因为"译错"（这类只占少数），而是三类：

1. **难读／不合汉语习惯**（最普遍）。典型："过于直译，且句式和语法实在不合中文习惯"
   （邓晓芒本，2017）；"有些地方不符合汉语规律，读起来有些拗口"（梁志学本）；"译文有不少句子
   不流畅甚至疑似不符合汉语规范"（杨祖陶本）。
2. **术语与译名别扭**。典型："很多译名看着别扭"（先刚本）；"很喜欢用两三个词叠在一起翻译同一个
   概念"（先刚《哲学全书·逻辑学》，2023）——**同一概念多个译名**，被指"凭空增添读者理解的负担，
   让译本在学术研究上的可用性更差"。
3. **读不懂＝内容本身太难**，与译本无关（大量差评其实是阅读进度打卡与自嘲）。

## 二、真正严重的翻译缺陷（有具体例证）

| 类型 | 例证（原评论） |
|---|---|
| **漏否定词／意思翻反** | 王志宏《哲学史讲演录Ⅰ》：p192 谈"爱智慧"，"它是一种永远得不到满足的欲望"，**漏了否定词**，应为"不是永远得不到" |
| **概念误认** | 同上：p202"一是**量的**存在"应为"**质的**存在"；p206 整句不通 |
| **漏被动语态** | 同上：p208"划定界限的东西"漏被动，应为"**被**划定界限的" |
| **术语译错** | 同上：p212 `Aufhebung` 译成"消灭"而非"**扬弃**"，且代词指代错误 |
| **漏译半句** | 同上：p248"你将找不到思维"后**漏译半句**"除了存在之外，没有任何东西" |
| **主语错乱／主客颠倒** | 燕宏远《宗教哲学讲演录1》：**"好多地方根本意思都翻反了…有句子前后两个分句的主语都完全调换了"**；邓安庆《法哲学原理》："意思相反，主语错乱" |
| **系统性语法误读** | 邓晓芒本（读者校对四个月后列出）：第三格 `sich` 常被译成"自己"，**应为"对自己而言"**；`es ist…` 常被译成"它是"，**很多地方其实是 there is** |
| **定语从句译两次** | 先刚《哲学全书·逻辑学》：**"定语从句被翻译两次"**，"怀疑是机翻没处理干净" |
| **一句拆成两句** | 同上："在不确定的地方把一句话翻译成两句话"，"殊不知却让翻译出来的句子更不通顺" |
| **拆长句伤论证层次** | 先刚《精神现象学》：**"经常把原文分号改成句号来拆散长句…会导致弄不清段内论证层次，反而增加阅读障碍，很多地方得挨个去对原文标点"** |
| **生造术语** | 读者共识："**翻译，大忌是造生词。中国人不懂，德国人不懂，只有作者一个人懂**"；邓安庆本把 `Real- und Konsensualkontrakt`（实践契约／诺成契约）生造为"实在契约／共识契约" |
| **法律专门词误译** | 同上：`Bonitarium` 旧译"裁判官法上的所有权"（正确），新译"判官法上的所有权"；帕斯卡尔《致外省人信札》误译为《给乡下人的信》 |
| **凭空出现的词** | 燕宏远本："这跟它必须以此经受住考验一样稀少"——**前文根本没讲什么"考验"** |
| **注释夹带私见** | 邓安庆本："不少自作聪明的注释"；先刚本："夹杂很多私货" |
| **删节（洁本）** | 刘立群《黑格尔全集》第27卷被指为"**洁本**"：几乎所有关于中国的尖锐评论消失，还多出高度赞美中国古代政府与皇帝的言论——"让人不由得怀疑是不是有两个黑格尔" |
| **专名被误改** | 梁志学、刘哲《自然哲学》：神话典故"密纳发从丘必特脑袋里跳出来"中的"**丘必特**"被改成"丘比特"（小爱神），系误改旧译名 |
| **多人合译水平参差** | 邓安庆本：译者注里"我们译成"与"我译成"混用；读者据此怀疑集体翻译 |
| **底本与编排** | 《宗教哲学讲演录》：底本（W16 友人版）本身"思路混乱、材料安排任意"，四次讲演的差异无法像英译本那样一目了然 |
| **意识形态腔** | 贺麟全集新版《精神现象学》读者评："缺陷：导言还是以一种**苏联及教科书式的体系**来进行哲学评论" |

## 三、正面评价给出的方向

- "翻译流畅明白"（先刚本正面评价）；
- 邓晓芒本"诸多表意也更加精准"，导言"相当好看"；
- 商务版（旧译）"语句就顺畅很多，很容易理解"；
- 先刚《哲学全书》被称赞的做法：**排版上能一眼分清正文、说明与 Zusatz；部分译名做了改进，
  如 `Gehalt` 译"内涵"以区别于 `Inhalt`［内容］**——即**近义术语必须区分**；
- 刘立群本"译者注很用心""译文流畅且反映近年研究成果"；
- 邓安庆本"译者序的版本考最有价值"。

## 四、对本项目的结论（仅供参考，不得用来改动政策）

**权威顺序**：用户的词族／术语政策最高；本卷术语包次之；共享词表再次；
**通行译名、其他中译本与下面这些读者评论仅供参考**——可以用来把工作做得更好，
但绝不能作为改动政策译名的理由（`scripts/check-policy.mjs` 对此有机器守卫）。

1. **长句不拆**：与我们既有的规则（"把 Hegel 的长句保留为一整句"）方向一致；拆句会让论证层次散掉。
2. **术语一一对应**：与我们术语包 + 符合性检查的目标一致。
3. **不造生词**：作为我们自己的规则写入所有卷级上下文包——但**术语首先服从词族政策**，
   政策未覆盖处才用通行译名；**不得为了"通俗"而改用与政策冲突的通行译名**。
4. **不漏否定／不漏被动／不漏半句**：新增机械检查——德文含否定词而中文无否定词即报 major。
   实测：全书 **5,738 句中仅 1 处触发，且经核实为德语冗余否定（`wie langsam … nicht`）**。
5. **定语从句只译一次**：新增中文句内重复片段检测（≥8 字重复）。
6. **反身代词与格、`es ist` 的 there is 用法**：作为译者的自查项写入上下文包。
7. **主宾切换显式化**：同上，作为自查项。
8. **不删节**：本项目为全文数字化，无删节；站点已注明底本与来源。
9. **专名不改旧译**：作为自查项（"丘必特→丘比特"的教训）。
10. **一个权威**：卷级术语包若与词族政策冲突，以政策为准——
    归一化实测修正了 w2 包中 `Idee→理念`、`Idealismus→唯心论` 等条目，一次性消掉 232 条误报。
11. **书名与学派名同样服从政策**：`Das älteste Systemprogramm des deutschen Idealismus`
    →《德国观念论最古老的体系纲领》，`System des transzendentalen Idealismus`
    →《先验观念论体系》，首次出现附德文原名。若保留通行书名，同一段里"观念论"与
    "《先验唯心论体系》"并置，等于又把词根联系割断——这与政策的目的直接冲突。
